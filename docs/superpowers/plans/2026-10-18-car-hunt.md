# Car Hunt Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn the single-family used-car tracker into a self-hosted app that anyone can run with their own search profile.

**Architecture:** Express server with JSON files in `DATA_DIR` (cars, meta, profile, photos). A single static page reads the profile and computes scores and criteria checks in the browser through a small shared module (`public/criteria.js`) that the tests also load. A setup wizard writes the profile on first launch. A Claude Code routine template does the marketplace scanning outside the app.

**Tech Stack:** Node ≥ 18, Express 4, plain browser JavaScript (no build step), Leaflet from cdnjs, `node --test`.

**Spec:** `docs/design.md`

## Global Constraints

- No personal data in this repository: no real names, addresses, phone numbers, listing photos or seller data. Examples use "Alex Example" and "Königsallee 1, 40212 Düsseldorf".
- Node ≥ 18; only runtime dependency is `express`.
- All interface text exists in English (`en`), German (`de`) and Brazilian Portuguese (`pt`).
- Every `/api/*` route and every page asset sits behind HTTP Basic auth when `SITE_PASSWORD` is set. Bulk listing writes additionally need the `x-sync-key` header matching `SYNC_KEY`.
- Writes to `DATA_DIR` are atomic (temp file + rename).
- Equipment keys everywhere: `carplay`, `camera`, `acc`, `ahk`, `led`, `pano`, `navi`, `seatheat`.
- Rating keys everywhere: `km`, `docs`, `gearbox`, `seller`, `price`, `distance`, `equip` (0–10).
- Score = round(Σ rating × weight ÷ Σ weights × 10), skipping missing ratings and zero weights.
- Commit messages carry no AI attribution lines.

## Source material

`$PATTERNS` is a file outside this repository listing the original owner's personal strings (name, address, coordinates, car ids). Every personal-data check greps for it; the strings themselves never appear here.


The starting code lives in a private repository on the author's machine (path `$SRC`): `$SRC/server.js`, `$SRC/public/index.html` and `$SRC/test/server.test.js`. Task 1 copies them in and strips personal data. Later tasks quote the exact lines they change.

```js
// lib/store.js — JSON files in DATA_DIR, written atomically.
const fs = require("fs");

function readJson(file, fallback) {
  if (!fs.existsSync(file)) return fallback;
  return JSON.parse(fs.readFileSync(file, "utf8"));
}

function writeJsonAtomic(file, value) {
  const tmp = file + "." + process.pid + "." + Date.now() + ".tmp";
  return fs.promises.writeFile(tmp, JSON.stringify(value)).then(() => fs.promises.rename(tmp, file));
}

module.exports = { readJson, writeJsonAtomic };
```

```js
// server.js — Car Hunt: static page + JSON API. Data lives in DATA_DIR.
const express = require("express");
const fs = require("fs");
const path = require("path");
const crypto = require("crypto");
const { readJson, writeJsonAtomic } = require("./lib/store");

const STATUSES = ["candidate", "contacted", "replied", "call", "viewing", "declined", "dropped", "bought"];
const LISTING_FIELDS = ["title", "shortName", "displayTitle", "make", "model", "fuel", "engine", "facelift", "variant", "trim", "colour", "price", "negotiable", "km", "regMonth", "regYear", "hp", "gearbox", "dsgType", "hu", "owners", "serviceHistory", "timingBelt", "dsgOil", "docsReview", "carplay", "carplayStatus", "camera", "location", "city", "distanceKm", "airKm", "roadKm", "driveMin", "transitMin", "transitCheckedAt", "transitSource", "transitDestination", "transitApproximate", "lat", "lon", "bahnUrl", "mapsUrl", "sellerName", "sellerType", "phone", "url", "kleinanzeigenUrl", "photos", "verdict", "pros", "cons", "questions", "i18n", "equip", "score", "rating", "replyAssessment", "visit", "order", "addedAt", "lastSeenAt", "priceHistory", "gone"];
const today = () => new Date().toISOString().slice(0, 10);

function createApp(options = {}) {
  const dataDir = options.dataDir || process.env.DATA_DIR || path.join(__dirname, "data");
  const password = options.password ?? process.env.SITE_PASSWORD ?? "";
  const syncKey = options.syncKey ?? process.env.SYNC_KEY ?? "";
  const seedFile = options.seedFile || path.join(__dirname, "seed.json");
  const files = { cars: path.join(dataDir, "cars.json"), meta: path.join(dataDir, "meta.json"), profile: path.join(dataDir, "profile.json") };
  fs.mkdirSync(path.join(dataDir, "img"), { recursive: true });

  const state = {
    cars: readJson(files.cars, null),
    meta: readJson(files.meta, { lastCheck: null, log: [] }),
    profile: readJson(files.profile, null)
  };
  if (!state.cars) {
    state.cars = {};
    if (process.env.SEED === "1") {
      const seed = readJson(seedFile, { cars: {} });
      state.cars = seed.cars || {};
      state.meta.lastCheck = seed.snapshotAt || null;
    }
    fs.writeFileSync(files.cars, JSON.stringify(state.cars));
  }

  let writing = Promise.resolve();
  const persist = () => (writing = writing.catch(() => {}).then(() => Promise.all([writeJsonAtomic(files.cars, state.cars), writeJsonAtomic(files.meta, state.meta)])));

  const app = express();
  app.locals.state = state;
  app.locals.files = files;
  app.locals.persist = persist;
  app.locals.fetchImpl = options.fetchImpl || globalThis.fetch;
  app.disable("x-powered-by");
  app.use(express.json({ limit: "4mb" }));
  app.use((req, res, next) => {
    res.set("X-Content-Type-Options", "nosniff"); res.set("X-Frame-Options", "DENY"); res.set("Referrer-Policy", "strict-origin-when-cross-origin");
    if (req.path.startsWith("/api/")) res.set("Cache-Control", "no-store");
    next();
  });

  if (password) {
    app.use((req, res, next) => {
      const [scheme, b64] = (req.headers.authorization || "").split(" ");
      const pass = scheme === "Basic" && b64 ? Buffer.from(b64, "base64").toString().split(":").slice(1).join(":") : "";
      const a = Buffer.from(pass), b = Buffer.from(password);
      if (a.length === b.length && crypto.timingSafeEqual(a, b)) return next();
      res.set("WWW-Authenticate", `Basic realm="${(state.profile && state.profile.name || "Car Hunt").replace(/"/g, "")}"`);
      res.status(401).send("Password required");
    });
  }

  const requireKey = (req, res, next) => {
    if (!syncKey) return res.status(503).json({ error: "SYNC_KEY not configured" });
    if (req.headers["x-sync-key"] !== syncKey) return res.status(401).json({ error: "bad sync key" });
    next();
  };
  app.locals.requireKey = requireKey;

  app.get("/api/cars", (req, res) => res.json({ cars: state.cars, updatedAt: new Date().toISOString() }));
  app.get("/api/meta", (req, res) => res.json(state.meta));

  app.patch("/api/cars/:id", async (req, res) => {
    const c = state.cars[req.params.id];
    if (!c) return res.status(404).json({ error: "unknown car" });
    const p = req.body;
    if (!p || typeof p !== "object" || Array.isArray(p)) return res.status(400).json({ error: "invalid update" });
    const allowed = ["status", "nextStep", "notes", "pick", "messages"];
    if (Object.keys(p).some(k => !allowed.includes(k))) return res.status(400).json({ error: "unsupported field" });
    if ("status" in p && !STATUSES.includes(p.status)) return res.status(400).json({ error: "invalid status" });
    if (["nextStep", "notes"].some(k => k in p && (typeof p[k] !== "string" || p[k].length > 10000))) return res.status(400).json({ error: "invalid text" });
    if ("pick" in p && typeof p.pick !== "boolean") return res.status(400).json({ error: "invalid pick" });
    if ("messages" in p && (!Array.isArray(p.messages) || p.messages.length > 200 || p.messages.some(m => !m || typeof m !== "object" || typeof m.text !== "string" || m.text.length > 10000))) return res.status(400).json({ error: "invalid messages" });
    for (const k of allowed) if (k in p) c[k] = p[k];
    try { await persist(); res.json({ ok: true, car: c }); } catch (e) { res.status(500).json({ error: "save failed" }); }
  });

  app.put("/api/cars/:id", requireKey, async (req, res) => {
    const id = req.params.id, incoming = req.body || {};
    if (!/^[a-z0-9][a-z0-9-]{0,79}$/.test(id)) return res.status(400).json({ error: "invalid id" });
    const listing = Object.fromEntries(Object.entries(incoming).filter(([k]) => LISTING_FIELDS.includes(k)));
    const prev = state.cars[id];
    state.cars[id] = prev ? { ...prev, ...listing } : { status: "candidate", pick: false, notes: "", nextStep: "", messages: [], addedAt: today(), ...listing };
    if (!prev && typeof incoming.pick === "boolean") state.cars[id].pick = incoming.pick;
    if (!prev) state.meta.log.unshift({ date: today(), type: "new", id, text: state.cars[id].displayTitle || state.cars[id].title, price: state.cars[id].price });
    await persist();
    res.json({ ok: true, created: !prev });
  });

  app.put("/api/meta", requireKey, async (req, res) => { Object.assign(state.meta, req.body || {}); await persist(); res.json({ ok: true, meta: state.meta }); });

  app.post("/api/sync", requireKey, async (req, res) => {
    const seen = (req.body && req.body.seen) || {}, d = today(), changes = [];
    for (const [id, c] of Object.entries(state.cars)) {
      const s = seen[id];
      if (s) {
        c.lastSeenAt = d;
        if (c.gone) { c.gone = false; changes.push({ date: d, type: "back", id, text: c.displayTitle }); }
        if (s.price && s.price !== c.price) { c.priceHistory = [...(c.priceHistory || []), { date: d, price: s.price }]; changes.push({ date: d, type: "price", id, text: c.displayTitle, from: c.price, to: s.price }); c.price = s.price; }
        if (s.km && s.km !== c.km) c.km = s.km;
      } else if (req.body.complete && !c.gone && !["bought", "declined", "dropped"].includes(c.status)) {
        c.gone = true; c.goneAt = d; changes.push({ date: d, type: "gone", id, text: c.displayTitle });
      }
    }
    state.meta.lastCheck = req.body.checkedAt || new Date().toISOString();
    state.meta.log = [...changes, ...state.meta.log].slice(0, 200);
    await persist();
    res.json({ ok: true, changes });
  });

  if (options.extraRoutes) options.extraRoutes(app);
  app.use("/img", express.static(path.join(dataDir, "img"), { maxAge: "1d" }));
  app.use(express.static(path.join(__dirname, "public"), { index: "index.html", setHeaders: (res, p) => res.set("Cache-Control", /\.(html|json|js)$/.test(p) ? "no-cache" : "public, max-age=86400") }));
  return app;
}

module.exports = { createApp, LISTING_FIELDS, STATUSES };

if (require.main === module) {
  const port = process.env.PORT || 3000;
  createApp().listen(port, () => console.log(`Car Hunt on :${port}`));
}
```

```js
// Validators push "path: message" into errs.
const isObj = v => v !== null && typeof v === "object" && !Array.isArray(v);
const str = (min, max) => (v, p, e) => { if (typeof v !== "string" || v.length < min || v.length > max) e.push(`${p}: text of ${min}–${max} characters expected`); };
const bool = (v, p, e) => { if (typeof v !== "boolean") e.push(`${p}: true or false expected`); };
```

```js
// lib/geo.js — Nominatim geocoding and OSRM driving time, with timeouts.
const UA = "car-hunt/0.1 (+https://github.com/DasMehl/car-hunt)";

async function getJson(fetchImpl, url, ms) {
  const ac = new AbortController();
  const timer = setTimeout(() => ac.abort(), ms);
  try {
    const r = await fetchImpl(url, { signal: ac.signal, headers: { "User-Agent": UA, "Accept-Language": "de,en" } });
    if (!r.ok) throw new Error("HTTP " + r.status);
    return await r.json();
  } finally { clearTimeout(timer); }
}

async function geocode(query, fetchImpl = globalThis.fetch, ms = 5000) {
  const j = await getJson(fetchImpl, "https://nominatim.openstreetmap.org/search?format=json&limit=1&q=" + encodeURIComponent(query), ms);
  if (!Array.isArray(j) || !j.length) return null;
  return { label: j[0].display_name, lat: +(+j[0].lat).toFixed(5), lon: +(+j[0].lon).toFixed(5) };
}

async function drive(from, to, fetchImpl = globalThis.fetch, ms = 5000) {
  const j = await getJson(fetchImpl, `https://router.project-osrm.org/route/v1/driving/${from.lon},${from.lat};${to.lon},${to.lat}?overview=false`, ms);
  const r = j && j.routes && j.routes[0];
  if (!r) return null;
  return { roadKm: Math.round(r.distance / 1000), driveMin: Math.round(r.duration / 60) };
}

module.exports = { geocode, drive };
```

```js
// public/criteria.js — detection, score and criteria check. Loaded by the page (window.Criteria) and by the tests.
(function (root, factory) {
  if (typeof module === "object" && module.exports) module.exports = factory();
  else root.Criteria = factory();
})(typeof self !== "undefined" ? self : this, function () {
  const WEIGHT_KEYS = ["km", "docs", "gearbox", "seller", "price", "distance", "equip"];
  const ALIASES = { volkswagen: "VW", vw: "VW", mercedes: "Mercedes-Benz", "mercedes-benz": "Mercedes-Benz", "škoda": "Skoda", skoda: "Skoda", "citroën": "Citroen", citroen: "Citroen", bmw: "BMW", ds: "DS", kia: "Kia", mini: "Mini", seat: "Seat", cupra: "Cupra" };

  function normMake(s) {
    if (!s) return null;
    const k = String(s).trim().toLowerCase();
    if (!k) return null;
    return ALIASES[k] || k[0].toUpperCase() + k.slice(1);
  }
  function makeOf(car) {
    if (car.make) return normMake(car.make);
    const name = String(car.model || car.title || "").trim();
    if (/^mercedes/i.test(name)) return "Mercedes-Benz";
    return normMake(name.split(/\s+/)[0]);
  }
  function fuelOf(car) {
    if (car.fuel) { const f = String(car.fuel).toLowerCase(); return /plug/.test(f) ? "plugin" : f; }
    const t = [car.engine, car.title, car.displayTitle].filter(Boolean).join(" ");
    if (/plug-?in|PHEV|e-?tron|\bGTE\b|\b\d{3}xe\b|\b\d{3}e\b/i.test(t)) return "plugin";
    if (/hybrid/i.test(t)) return "hybrid";
    if (/electric|\bEV\b|e-Golf|kWh/i.test(t)) return "electric";
    if (/\bLPG\b|Autogas/i.test(t)) return "lpg";
    if (/TDI|diesel|CDI|CDTI|dCi|HDi|CRDi|D-4D|\b\d{3}d\b/i.test(t)) return "diesel";
    if (/TSI|TFSI|petrol|benzin|gasoline|\b\d{3}i\b|MPI|Skyactiv-G/i.test(t)) return "petrol";
    return null;
  }
  function gearboxOf(car) {
    const t = [car.gearbox, car.dsgType].filter(Boolean).join(" ");
    if (/manual|schalt/i.test(t)) return "manual";
    if (/auto|DSG|DCT|tronic|CVT|steptronic|torque/i.test(t)) return "automatic";
    return null;
  }
  function scoreCar(car, weights) {
    const r = car.rating;
    if (!r) return car.score ?? null;
    let sum = 0, w = 0;
    for (const k of WEIGHT_KEYS) {
      const wk = Number((weights || {})[k] || 0);
      if (r[k] == null || !wk) continue;
      sum += Math.max(0, Math.min(10, r[k])) * wk; w += wk;
    }
    return w ? Math.round(sum / w * 10) : null;
  }
  function avoidHits(car, profile, catalogue) {
    const text = [car.engine, car.dsgType, car.gearbox, car.title, car.displayTitle, car.model, car.variant].filter(Boolean).join(" | ");
    const make = makeOf(car), fuel = fuelOf(car), ym = (car.regYear || 0) * 100 + (car.regMonth || 1);
    const hits = [];
    for (const a of profile.avoid || []) {
      if (!a.on) continue;
      const def = a.id.startsWith("custom-") ? { id: a.id, label: { en: a.label, de: a.label, pt: a.label }, reason: { en: "", de: "", pt: "" }, test: a.match } : (catalogue || []).find(d => d.id === a.id);
      if (!def) continue;
      if (def.makes && !def.makes.includes(make)) continue;
      if (def.fuel && fuel && def.fuel !== fuel) continue;
      if (def.from && car.regYear && ym < def.from) continue;
      if (def.to && car.regYear && ym > def.to) continue;
      if (def.test && !new RegExp(def.test, "i").test(text)) continue;
      hits.push(def);
    }
    return hits;
  }
  function checkCriteria(car, profile, catalogue) {
    const p = profile, out = [];
    const fuel = fuelOf(car);
    if (fuel && !p.car.fuels.includes(fuel)) out.push({ key: "fuel", value: fuel });
    const gb = gearboxOf(car);
    if (p.car.gearbox !== "any" && gb && gb !== p.car.gearbox) out.push({ key: "gearbox", value: gb });
    const make = makeOf(car);
    if (make && !(p.car.exceptions || []).includes(car.id)) {
      const inc = (p.car.makes.include || []).map(normMake), exc = (p.car.makes.exclude || []).map(normMake);
      if (exc.includes(make) || (inc.length && !inc.includes(make))) out.push({ key: "make", value: make });
    }
    if (car.price != null && !(car.price <= p.money.maxPrice || (car.negotiable && car.price <= p.money.negotiableUpTo))) out.push({ key: "price", value: car.price });
    if (car.km != null && car.km > p.car.maxKm) out.push({ key: "km", value: car.km });
    if (car.regYear && (car.regYear < p.car.yearFrom || (p.car.yearTo && car.regYear > p.car.yearTo))) out.push({ key: "year", value: car.regYear });
    if (car.hp && p.car.minHp && car.hp < p.car.minHp) out.push({ key: "hp", value: car.hp });
    if (car.driveMin != null && car.driveMin > p.distance.maxDriveMin) out.push({ key: "drive", value: car.driveMin });
    for (const k of p.equipment.must || []) if (!(((car.equip || {})[k] || 0) >= 0.6)) out.push({ key: "equip", value: k });
    for (const d of avoidHits(car, p, catalogue)) out.push({ key: "avoid", value: d.id, def: d });
    return out;
  }
  return { WEIGHT_KEYS, normMake, makeOf, fuelOf, gearboxOf, scoreCar, avoidHits, checkCriteria };
});
```

```markdown
---
name: car-hunt-listing-check
description: Every few hours, scan mobile.de with the Car Hunt profile, add and rate new cars, record price changes, read seller replies and, if allowed, send one short first message per shortlisted car.
---

You maintain a Car Hunt tracker. Fill in the two values below once when installing.

- SITE: `https://YOUR-SITE.up.railway.app`
- Password and sync key: stored in files you choose, e.g. `~/.car-hunt/password` and `~/.car-hunt/sync-key`. Send the password as HTTP Basic auth on every request (`curl -s -u ":$PW" "$SITE/api/cars"`) and the sync key as header `x-sync-key` for bulk writes.

## 0. Read the profile first

`GET $SITE/api/profile`. Every rule below comes from it. If it returns 404, stop and tell the owner to finish the setup wizard on the site.

API: `GET /api/cars` → `{cars: {id: car}}`; `GET /api/meta`; `PATCH /api/cars/<id>` (password only) for `status`, `nextStep`, `notes`, `pick`, `messages`; `PUT /api/cars/<id>` (password + sync key) merges listing fields; `POST /api/sync` (password + sync key) `{"seen": {id: {price, km}}, "complete": true, "checkedAt": ISO}`; `PUT /api/img/<id>-1.jpg` (password + sync key, `Content-Type: image/jpeg`) stores a photo and returns its path.

## 1. Build the searches

Base URL `https://suchen.mobile.de/fahrzeuge/search.html?isSearchRequest=true&dam=false&s=Car&vc=Car&cn=DE&sb=doc&od=down&lang=de` plus:
- price `p=%3A<negotiableUpTo>`, mileage `ml=%3A<car.maxKm>`, year `fr=<car.yearFrom>%3A<car.yearTo or empty>`, power `pw=<round(minHp × 0.7355)>%3A` when minHp > 0;
- location `ll=<home.lat>%2C<home.lon>` and radius `rd=` = maxDriveMin × 1.25 km rounded up to one of 10, 20, 50, 100, 150, 200;
- gearbox `tr=AUTOMATIC_GEAR` or `tr=MANUAL_GEAR` (omit for "any");
- one search per fuel: `ft=DIESEL`, `ft=PETROL`, `ft=HYBRID` are verified; for plug-in, electric and LPG open mobile.de's search form, choose the fuel and copy the `ft=` value from the URL;
- one search per body: `c=EstateCar`, `c=Limousine` (hatchback and saloon), `c=Van` are verified; for SUV, coupé and convertible read `c=` from the search form the same way;
- makes: if `car.makes.include` is not empty, one search per make with `ms=<id>%3B%3B%3B`. Verified ids: VW 25200, Seat 22500, Audi 1900, BMW 3500, Mercedes-Benz 17200, Toyota 24100. For other makes read `ms=` from the search form.

Open one mobile.de page in the browser tool, decline cookies, then `fetch` each search with `&pageNumber=1..5` from that tab and parse with DOMParser (plain curl gets 403). For each `a[href*="details.html"]` above "Ähnliche Fahrzeuge": listing id, title, price, km, first registration, kW, seller type, postcode and town. Stop when a page adds no new ids. Skip damaged, export- or trade-only, taxi and rental cars.

## 2. Sync and new cars

- `seen = {trackerId: {price, km}}` for tracked cars that still appear; `POST /api/sync` with `complete: true`.
- New listings = ids not contained in any tracked `url` or `kleinanzeigenUrl`. Fetch each detail page (`/fahrzeuge/details.html?id=<id>&lang=de`) for HU, owners, service book, accident-free, description (timing belt or chain, gearbox oil), equipment, dealer rating and all image ids (`img.classistatic.de/api/v1/mo-prod/images/<xx>/<uuid>`).
- Apply the profile before adding: fuel, gearbox, body, seats, makes (`exclude` never; `include` only), year, mileage, power, price (`maxPrice`, or up to `negotiableUpTo` when the listing says negotiable/VB), and driving time from home ≤ `distance.maxDriveMin` (OSRM below). Check `avoid`: for every entry with `on: true`, read its definition in `$SITE/drivetrains.json` (custom entries carry their own `match`) and skip matching cars. Adding nothing is fine.
- Look for the same car on Kleinanzeigen; if it is a tracked car, store that link in `kleinanzeigenUrl` instead of adding a duplicate.

### Photos and documents
Download every photo at `?rule=mo-640`, build a contact sheet (`magick montage -tile 6x -geometry 320x240+6+6 *.jpg sheet.jpg`) and look at it. Read document photos (service book, invoices, stickers, odometer) at `?rule=mo-1600`. Write `docsReview` from what the photos prove. Upload the two best photos with `PUT /api/img/<id>-1.jpg` and `-2.jpg` and set `photos` to the returned paths.

### Distance
Geocode "postcode town, Germany" with Nominatim (1 request per second, a descriptive User-Agent), then OSRM `https://router.project-osrm.org/route/v1/driving/<home.lon>,<home.lat>;<lon>,<lat>?overview=false` for `roadKm` and `driveMin`. If `distance.preferTransit` is true, also plan a weekday 10:00 journey with Transitous (`https://api.transitous.org/api/v1/plan?fromPlace=<home.lat>,<home.lon>&toPlace=<lat>,<lon>&time=<ISO>`) and store `transitMin`, `transitCheckedAt`, `transitSource`, `transitDestination`, `transitApproximate`.

### The record
`PUT /api/cars/<id>` with id `<model>-<town>` (lowercase ASCII, unique). Fields: title, displayTitle ("<Make> <Model> <Body> <Trim> · <year>"), make, model, fuel, engine, price, negotiable, km, regMonth, regYear, hp, gearbox, dsgType (name the gearbox and its known risk), hu, owners, serviceHistory, timingBelt, dsgOil, docsReview, carplay, camera, location, city, sellerName, sellerType ("Dealer, 4.8★ (120)" or "Private"), url, photos, equip {carplay, camera, acc, ahk, led, pano, navi, seatheat as 0, 0.3, 0.6 or 1}, lat, lon, roadKm, driveMin, verdict (two sentences), pros, cons, questions, `rating` {km, docs, gearbox, seller, price, distance, equip} from 0 to 10, translations in `i18n.<lang>` for every language in `profile.languages` other than English, addedAt, lastSeenAt, priceHistory. Do not send `score`: the page computes it from `rating` and `profile.weights`. Set `pick: true` when the computed score (Σ rating × weight ÷ Σ weights × 10) is 65 or more.

Rating guide: km ≤ 70 % of maxKm 9–10, ≤ 85 % 7, ≤ 100 % 5. docs: full history with belt and gearbox oil proven 9–10, full history 7–8, described only 5–6, nothing 2–4. gearbox: torque converter or wet dual-clutch 9, dry dual-clutch 5, lower when the oil was never changed. seller: well-rated dealer 8–9, small dealer 7, private 4. price: well under maxPrice 9–10, at maxPrice 7, negotiable range 5. distance: ≤ 50 % of maxDriveMin 10, ≤ 100 % 7–8. equip: every nice-to-have 9–10, half 7, none 4.

## 3. Replies (browser where the owner is logged in)

mobile.de message center (`https://www.mobile.de/message-center`) and the owner's email for seller replies. For each new reply PATCH `messages` with `{date, dir: "in", from, via, text, i18n}`, set `status` (`replied`, `call` if they ask for a call, `declined` if sold or trade-only) and a concrete `nextStep`. Update the facts and `rating` with PUT, and set `replyAssessment` `{score 0–10, summary per language, assessedAt}`. Keep `visit` `{rank, why, next}` on the 3–5 replied cars most worth seeing; remove with `{"visit": null}`.

## 4. First messages (only if `outreach.enabled`)

If `outreach.enabled` is false, stop here.

For each car with `pick: true`, status `candidate`, not gone:
1. Duplicate check, every time, no exceptions: search the tracker (`sellerName`, `url`, `kleinanzeigenUrl`, all message texts), the mobile.de message center and the owner's email for the seller name, the listing id and the listing title (Kleinanzeigen replies arrive as "Re: Nutzer-Anfrage zu deiner Anzeige …"). If any contact exists, do not send; PATCH `status: "contacted"` with a note naming the existing conversation.
2. Re-fetch `GET /api/cars` right before sending; if a message was logged meanwhile, do not send.
3. Write a short, friendly first message in `outreach.language`, signed `outreach.senderName`, with at most three questions: still available and accident-free; service history and gearbox maintenance documented; when a viewing is possible.
4. Send it through `https://www.mobile.de/checkout/core/<listingId>`. It counts as sent once the page title says "Anfrage erfolgreich gesendet". Never send again because a confirmation seems missing; tell the owner instead.
5. PATCH immediately: `status: "contacted"`, `nextStep: "Wait for reply"`, and the outgoing message in `messages`.

## 5. Report

Short summary: searches run, new cars (title, price, km, town, score, drive time), price changes, cars gone, replies read, messages sent or skipped as duplicates.
```
